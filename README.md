### 🛠️ 工位上的日常

来自中南大学，在嵌入式、FPGA 和 Python 之间探索。这里放着我的硬件改造、算法实验，还有一些让日常更有趣的小工具。

- **电路与固件** — ESP32、WCH 单片机、USB / BLE 键盘与电容触摸。
- **软硬件协同** — Zynq UltraScale+、Vivado / Vitis、视觉拼图与 PL 加速。
- **灵感与工具** — Python 几何算法、图像处理、参数化建模与拼豆图纸。
